# 虚拟机的介绍、认识、演示和用途

VMware Workstation 可以在一台电脑（主机）上运行另一套操作系统（客户机）。开发时可以在客户机里安装软件、改配置、测试和调试程序，减少对主机工作环境的影响。共享文件夹、拖放和网络设置会影响两者的隔离程度。

| 想做什么 | 在 VMware Workstation 里怎么做 |
| --- | --- |
| 反复测试同一套环境 | 在安装软件或改配置前拍快照，并用“IDE 已装好”这样的名称标记状态。要重做测试时，在快照管理器里选中该快照并恢复。若还要保留当前进度，恢复前先给当前状态拍快照。 |
| 把配好的环境移到另一台电脑 | 先关闭客户机，再复制或打包整个虚拟机目录。在目标电脑上用 Workstation 打开目录里的 `.vmx` 配置文件。系统和数据保存在 `.vmdk` 虚拟磁盘里，迁移时要一起带上。 |
| 从主机传入测试文件 | 在支持并启用拖放的环境里，把文件从主机拖到客户机桌面，再到客户机内打开。 |
| 中断工作，下次接着做 | 选择“挂起”，把当前运行状态保存到磁盘。下次选择“继续运行”，就能回到原先打开的桌面和程序。 |
