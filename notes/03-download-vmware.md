# 虚拟机的下载

按**运行 VMware 的电脑**选择安装包。例如，在 Windows 电脑上创建 Linux 虚拟机，应下载 Windows 版 Workstation Pro。

| 电脑上的系统 | 官方下载入口（需登录） |
| --- | --- |
| Windows 或 Linux | [VMware Workstation Pro](https://support.broadcom.com/group/ecx/productdownloads?freeDownloads=true&subfamily=VMware+Workstation+Pro) |
| macOS | [VMware Fusion Pro](https://support.broadcom.com/group/ecx/productdownloads?freeDownloads=true&subfamily=VMware+Fusion) |

1. 登录 Broadcom Support Portal。首次使用可用邮箱注册普通账号（Basic），完成邮箱验证。普通账号可以下载免费产品，无需 Site ID。[Broadcom 下载指南](https://knowledge.broadcom.com/external/article/368734/download-desktop-hypervisor-workstation-and-fusion-products)
2. 从上表进入产品页，选择与主机系统相符的版本。如果从门户首页进入，在 **VMware Cloud Foundation → My Downloads → Free Software Downloads available HERE** 中搜索 `Workstation` 或 `Fusion`。[免费软件下载步骤](https://knowledge.broadcom.com/external/article/397417/downloading-free-software-from-the-broad.html)
3. 打开 **Terms and Conditions** 阅读条款，返回下载页勾选同意，再点安装包旁的下载图标。若首次下载时出现资料核验，按要求用英文字符如实填写姓名、地址和国家或地区。看到 `Account verification is pending` 表示审核仍在进行；资料完整却一直无法下载时，可联系 Broadcom Customer Care。[账号审核说明](https://knowledge.broadcom.com/external/article/368588/)

**免费使用范围**：Workstation Pro 17.5.2、Fusion Pro 13.5.2 及后续版本可免费用于个人、教育和商业用途，无需许可证密钥。[Broadcom 授权说明](https://knowledge.broadcom.com/external/article/368667/download-and-license-vmware-desktop-hyper.html)
